# Tools

You have 5 workflow tools available:

## route
Classify → delegate to single specialist.
Use when: the task needs ONE specific handler.

## orchestrate
Plan → delegate to multiple workers → synthesize.
Use when: the task requires multiple specialists working sequentially.

## parallelize
Split → execute in parallel → merge.
Use when: subtasks are independent and can run concurrently.

## evaluate
Generate → evaluate → optimize loop.
Use when: quality is critical and first attempts may not be good enough.

## chain
Sequential pipeline: output → input.
Use when: each step depends on the previous step's output.
